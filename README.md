# Computer Vision

A collection of practical examples and implementations covering **Computer Vision, image processing, and OpenCV using Python**.

## Technologies

- Python
- OpenCV
- NumPy
- Matplotlib
- Pillow

## Topics Covered

- Image Representation with NumPy
- Reading and Displaying Images
- Image Resizing
- Image Cropping
- Image Color Spaces
- Image Transformations
- Image Filtering and Blurring
- Edge Detection
- Thresholding
- Contour Detection
- Object Detection

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/computer_vision_learning.git
cd computer_vision_learning
```

**2. Create a virtual environment**

```bash
python3 -m venv .venv
```

**3. Activate the environment**

Linux / Ubuntu:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

**4. Install dependencies**

```bash
pip install -r requirements.txt
```

## Run

Execute a Python example using:

```bash
python main.py
```
